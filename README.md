# 座位表生成器 (Seat Map Generator)

一个基于 HTML/CSS/JavaScript 的交互式座位表生成工具，支持自定义座位布局、员工名单管理、拖拽分配座位，并可导出为图片。

## 功能特点

- 🪑 **自定义座位布局** - 支持设置行数和每行列数（日字格，两人面对面）
- 👥 **部门分类管理** - 支持按部门对员工进行分类，不同部门用不同颜色区分
- 🖱️ **拖拽分配座位** - 支持鼠标拖拽员工姓名到座位，座位间也可互换
- 💾 **自动保存** - 所有操作自动保存在浏览器中，下次打开自动恢复
- 📤 **导出图片** - 可导出座位总览图为 PNG 图片
- 📥 **导入名单** - 支持从 TXT 或 CSV 文件导入员工名单

## 使用说明

1. 打开网页后，默认已生成 100 个示例员工
2. 在"行列设置"区域调整总行数和每行列数
3. 员工名单格式：`部门-姓名`（如 `武汉分部-张三`）
4. 从待分配区拖拽员工到座位
5. 点击已分配座位的员工可撤销分配
6. 点击空座位可切换为 `/`（表示不坐人）
